# Inception-of-Things

A 42 System Administration project introducing Kubernetes with K3s, K3d, Vagrant, and Argo CD.

## Structure

```
├── p1/          # Part 1: K3s cluster with 2 VMs (Server + Worker)
├── p2/          # Part 2: K3s with 3 apps and Ingress routing
├── p3/          # Part 3: K3d with Argo CD (GitOps)
└── docs/        # Documentation and study guide
```
